`padding-right: capsuleRight`，flex 居中的结果是被推左约 48px（375 屏）。

- 内缩框本身即安全区：左边不压返回键，右边不压胶囊和查询键，长标题只在框内省略

  抬 `z-index: 1` 兜底，否则标题会吃掉按钮点击

  实测 `textCenter == phoneCenter`（偏移 0.00），且与任何按钮 `overlap=false`。
  像素扫描法不可用 —— 深色主题下整块背景都是「深色像素」，会把包围盒撑满

**检索 → 查询**

## 「我的」页真机布局修复（用户反馈：模拟器与预览图不一致）

用户指出两处：
1. 「分享给好友」的分享图标与右箭头靠太近，没有两端对齐 → 参考「分享到朋友圈」的布局
2. 「点击设置昵称」「已收藏 0 首」要靠近头像

**根因（延续此前教训）**：预览脚本是 div 模拟，Chrome 里 div 的 flex/margin 表现
和微信 `<button>` 不一致，所以预览图"看着正常"≠真机正常。**button 特有的坑预览
永远验不出来，必须以模拟器为准。**

### 落地

- **头像按钮**：`flex: none`（=0 0 auto，basis 仍取 width）改为显式
  `flex: 0 0 132rpx` + `display: block`。微信 button 默认 block 且有占满整行的倾向，
  在 flex 里若 basis 解析异常会被撑宽 → 右侧 `.me__info` 挤掉到下一行，
  昵称/收藏数就"远离头像"了。显式 basis 一刀切断。
- **`.me__info`** margin-left 从 `--s-4`(32rpx) 收到 `--s-3`(24rpx)，昵称/收藏更贴头像。
- **分享行（button）**：结构上把「图标+文字」包进 `.row__lead`（display:flex），
  容器改 `justify-content: space-between`——两个 flex 子项（lead / 箭头）顶到两端。
  弃用 `margin-left: auto`（button 内不可靠）也不再依赖空 value 占位
  （button 里空 view 撑不开）。
- preview.py 的 mine() 同步 `.row__lead` 结构；CSS 直接加载真实 wxss 所以样式自动跟随。

### 验证

- check.py：140 个 class 引用 0 未定义
- 预览重渲染：分享行两端对齐 ✓。但再次强调：div 预览对 button 无保真力，
  需模拟器/真机复核（头像是否仍占整行、分享行是否两端对齐）。

### 「分享给好友」二次修复（用户反馈：仍横向居中，不是两端对齐）

上一轮给 button 加 `display:flex; justify-content:space-between` 在真机上
**没用**——微信 `<button>` 自带 `display:flex; justify-content:center`，类选择器
`button`/`.row--btn` 盖不住它的内置默认，于是内容被默认 center 吃掉 → 横向居中。
div 预览里 flex 能正常 space-between，所以又被预览骗了。

**根治**：不让 button 承担布局。把布局搬给普通 view（`.row__share`：flex +
space-between + min-height，view 的 flex 在真机 100% 可靠），button
（`.row__share-btn`）退化为**满宽透明触发区**（flex:1, width:100%, padding:0,
background:transparent, border-radius:0），`open-type="share"` 点击热区仍是整行。
结构：`.row__share(view, space-between)` > [ `.row__share-btn`(满宽, 内含
`.row__lead`=图标+文字) , `.row__arrow` ]。
- mine.wxss：删 `.row--btn`，新增 `.row__share` / `.row__share-btn`
- mine.wxml：分享行改上述结构；preview.py 同步
- check.py 141 个 class 0 未定义
- 仍需模拟器确认：两端对齐 + 箭头位置 + 整行可点分享

**教训（写进长期笔记）**：凡是要用 `<button>` 承载复杂布局（flex 两端对齐等），
在真机里类选择器覆盖不了 button 的内置 flex:center，一律把布局交给外层 view，
button 只留作「满宽透明触发区 + open-type/事件」。

### 「分享给好友」文字偏粗修复（用户反馈看着像加粗）
